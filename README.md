# nova-ai-data-intelligence
AI-powered data analysis and interactive dashboard built with Python and Streamlit.
NOVA — AI Data Intelligence
NOVA is a Streamlit-based data analytics dashboard for exploring uploaded datasets, reviewing data quality, and viewing financial and category insights.
Live Demo
Add your deployed Streamlit Community Cloud URL here after deployment.
Features
- Upload CSV and Excel files
- Data cleaning options and data-quality checks
- Interactive dashboard and visualizations
- Financial and category insights
- Ask Your Data analysis
- Demo data available when no file is uploaded
Run locally
Python 3.10 or newer is recommended.
python -m pip install -r requirements.txt
python -m streamlit run app.py
Deploy free on Streamlit Community Cloud
1. Push this repository to your GitHub account.
2. Open https://share.streamlit.io/ and sign in with GitHub.
3. Choose Create app, select this repository and branch, and set the main file path to app.py.
4. Deploy and wait for the app to build.
5. Add the resulting public app URL to the Live Demo section above and to your CV.
Privacy note
Do not upload private customer data, passwords, API keys, or other secrets to this public repository. When testing the app, use sample or anonymized data.
